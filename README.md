# AI Data Science Job Market Analysis

## Project Overview

This project performs end-to-end Exploratory Data Analysis (EDA) on an AI and Data Science Job Market dataset containing 50,000 job postings.

The project includes:

- Data understanding
- Data cleaning and preprocessing
- Univariate and bivariate analysis
- Statistical hypothesis testing
- Feature engineering
- Business insight generation

---

## Dataset

- Records: 50,000
- Countries: 6
- Industries: 5
- Job Titles: 6

## Key Insights

- Experience strongly influences salary.
- Senior roles earn the highest compensation.
- Remote and onsite jobs show similar salary distributions.
- AI/Data Science demand remained stable across years.
- Dataset quality was excellent with no missing values or duplicates.
